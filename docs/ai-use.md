# Use of AI in this project

The Datanomics Tech team used **Claude (Anthropic)** as an AI assistant while building RIDIP, as the competition rules allow. This note sets out what it was used for and how the work was checked.

## What the AI helped with

- Drafting the project brief, blueprint, pitch deck and design diagrams.
- Writing and explaining code: the FastAPI backend, database setup, data pipeline, analytics (need scores, significance tests, k-means grouping, insight rules), tests and the React app.
- Locating official NISR tables and extracting their values: EICV7 reports, FinScope 2024, SAS 2025 and LFS 2025.
- Step-by-step guidance for the development environment, GitHub and deployment.
- Drafting this documentation.

## What the AI did not do

- RIDIP itself does not use a language model. The insights in the app are generated by fixed, documented rules from the official figures ([methodology](methodology.md)).
- No personal, confidential or household-level data was given to the AI. RIDIP uses only published, aggregated statistics.

## How the team stayed in control

- Every code change was run and tested on a team member's computer before being merged through a GitHub pull request.
- Extracted figures were checked against the source tables: poverty row by row, FinScope by its 100% totals and chart order, and sample values in automated tests.
- Decisions on scope, tracks, indicators, design and data sources were made by the team.

The team takes full responsibility for the submitted work.
